# Dataset Information

**Dataset Name:** Cassava Leaf Disease Classification

**Source:** Kaggle Competition

**Dataset Link:** https://www.kaggle.com/competitions/cassava-leaf-disease-classification

**Task:** Multi-class Image Classification

**Number of Classes:** 5

**Classes:**
1. Cassava Bacterial Blight (CBB)
2. Cassava Brown Streak Disease (CBSD)
3. Cassava Green Mottle (CGM)
4. Cassava Mosaic Disease (CMD)
5. Healthy

**Note:** The dataset will be downloaded and used on Google Colab. Large dataset files will not be uploaded to GitHub.
