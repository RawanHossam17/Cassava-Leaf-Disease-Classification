# Cassava Leaf Disease Classification

## Project Overview
This project aims to classify cassava leaf diseases using Deep Learning.

The project is based on the research paper:

"Less is More: Lighter and Faster Deep Neural Architecture for Tomato Leaf Disease Classification"

We will study and implement the proposed architecture using a different dataset: Cassava Leaf Disease Classification.

## Dataset
- **Name:** Cassava Leaf Disease Classification
- **Source:** Kaggle
- **Task:** Multi-class Image Classification
- **Number of Classes:** 5

## Disease Classes
1. Cassava Bacterial Blight (CBB)
2. Cassava Brown Streak Disease (CBSD)
3. Cassava Green Mottle (CGM)
4. Cassava Mosaic Disease (CMD)
5. Healthy
